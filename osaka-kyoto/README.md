# 大阪・京都 2026 行程網站

手機可用的靜態行程網站。點選地點名稱或地圖按鈕，會在 Google Maps 搜尋該地點；IG 按鈕保留 Word 文件內的原始連結。

## 功能

- 依日期瀏覽、搜尋、收藏與標記完成。
- 新增、編輯、刪除、移動日期與調整順序。
- 每次修改先儲存在這台裝置。可下載及匯入 JSON 備份。
- 使用同一 Google 帳號跨裝置同步。

## 雲端同步

Firebase 專案、Google 登入、授權網域及 Firestore 規則已設定。網站使用者在「同步」頁以 Google 登入；同一個帳號在其他裝置登入後，會讀取相同行程。

Firebase Web App 設定值可公開；安全性取決於 Firestore 規則。不要把服務帳戶私鑰或其他機密放進此儲存庫。
