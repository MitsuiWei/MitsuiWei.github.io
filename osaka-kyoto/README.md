# 大阪・京都 2026 行程網站

旅行日期：2026 年 11 月 28 日至 12 月 5 日，共 8 天。

手機可用的靜態行程網站。點選地點名稱或地圖按鈕，會在 Google Maps 搜尋該地點；IG 按鈕保留 Word 文件內的原始連結。

## 功能

- 依日期瀏覽、搜尋、收藏與標記完成。
- 新增、編輯、刪除、移動日期與調整順序。
- 免登入，所有訪客共用同一份雲端行程，修改會即時同步。
- 可下載及匯入 JSON 備份；匯入會取代所有人的共用行程。

## 共用行程

共用行程儲存在 Firebase Firestore 的 `sharedTrips/osaka-kyoto-2026`。只有這份行程允許公開讀取與編輯，其他使用者資料仍依原有規則隔離。網站需要連上雲端才能修改。

公開連結的任何訪客都能編輯、刪除或匯入共用行程，應定期下載備份。

Firebase Web App 設定值可公開；安全性取決於 Firestore 規則。不要把服務帳戶私鑰或其他機密放進此儲存庫。
